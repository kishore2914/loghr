# Font Setup for Rupee Symbol (₹) in PDF

To display the Rupee symbol (₹) correctly in PDF payslips, you need to add a Unicode-compatible font.

## Steps:

1. **Download Noto Sans font:**
   - Visit: https://fonts.google.com/noto/specimen/Noto+Sans
   - Click "Download family" or download "Noto Sans Regular"
   - Extract the ZIP file

2. **Add the font file:**
   - Copy `NotoSans-Regular.ttf` from the downloaded fonts
   - Paste it into this folder: `assets/fonts/NotoSans-Regular.ttf`

3. **Run the app:**
   - The PDF service will automatically load the font
   - The Rupee symbol (₹) will now display correctly in PDFs

## Alternative Fonts:
- DejaVu Sans (also supports Unicode)
- Arial Unicode MS (if available on your system)

The font file should be named exactly: `NotoSans-Regular.ttf`
